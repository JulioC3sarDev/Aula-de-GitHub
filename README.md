# Aula-de-GitHub
Tudo que for feito na aula de Desenvolvimento Mobile


Atividade em dupla: (Júlio e Eduarda)

Criar ambos um repositório e cada um fazer um push de um código com erro e cada um fazer uma fork e corrigir o erro e fazer um pull request e ambos aceitar e fazer um merge! e enviar ao professor pelo email!

Estudar a teoria do git flow e fazer uma pesquisa de máximo de 2 paginas com suas palavaras e trazer exemplos práticos de gitflow.
